# 标注规范 · GC10-DET 十类缺陷（Labeling Spec）

> 这份文档回答四个问题：**十类缺陷怎么定义、框怎么画、边界案例算不算、什么不该标。**
>
> 规范的作用不是让标注员「更认真」，而是把那些本来会吵起来的边界案例，提前用规则钉死。先看一个具体的例子：`crease` 和 `water_spot` 在混淆矩阵里互混 25%（见 [`EVAL.md`](EVAL.md) 的混淆矩阵一节）。这不是模型问题——这两类在灰度图上本来就难以区分，区分它们需要工艺知识而不是视觉信息。同一张图交给两个标注员，很可能得到两个不同的答案。
>
> 下面第 1 节给类别定义，第 2 节给画框规则，第 3、4 节处理歧义，第 7 节列禁标情形。产线自建数据集时，第 5 节的流程和第 6 节的质检规则同样适用。

---

## 1 十类定义（Class definitions）

| # | 英文名 | 中文名 | 定义 | 典型尺寸（原图 px） | 训练实例数 |
|---|---|---|---|---|---|
| 0 | crease | 折痕 | 钢带在卷取或轧制中受机械挤压形成的**线状/条状折线**，走向通常与轧制方向一致，边缘相对锐利 | 长 200–1000，宽 10–40 | 74 |
| 1 | crescent_gap | 月牙形缺口 | 钢带边缘或内部的**月牙形/弧形缺口**，是板边剪切或轧辊咬入造成的材料缺失 | 80–400 | 265 |
| 2 | inclusion | 夹杂 | 钢坯中残留的**非金属夹杂物**（氧化物、硫化物），表现为暗色不规则小点/小块，边缘相对锐利 | **30–60** | 347 |
| 3 | oil_spot | 油斑 | 轧制油或润滑油在钢带表面形成的**油渍**，暗色、边缘模糊弥散，常成片分布 | 60–500 | 569 |
| 4 | punching_hole | 冲孔 | 后续工序打的**规则圆孔/方孔**，形状规则、边缘锐利、内部为全黑（透空） | 40–200 | 329 |
| 5 | rolled_pit | 轧制坑 | 轧辊表面缺陷压印在钢带上形成的**浅凹陷**，明暗过渡柔和，无明显锐利边缘 | 150–300 | 85 |
| 6 | silk_spot | 丝斑 | 钢带表面的**丝状/网状纹理异常**，成片分布，与正常压下量纹理混淆度最高 | 150–1000，常互相重叠 | 884 |
| 7 | waist_folding | 腰部折 | 钢带中部（腰部）的**折叠/皱褶**，形态不规则，通常伴随亮度突变 | 100–600 | 143 |
| 8 | water_spot | 水斑 | 冷却水残留形成的**水渍**，亮色或暗色片状区域，边缘模糊、形状随意 | 80–400 | 354 |
| 9 | welding_line | 焊缝线 | 钢带**对接焊缝**及热影响区，贯穿整个板宽的长条状亮/暗带 | 长 = 整幅，宽 20–120 | 513 |

**共 3563 个标注框，2300 张图。类别极度不均衡：最多（silk_spot 884）是最少（crease 74）的 12 倍。**

## 2 边界框规则（Box rules）

框怎么画，比类别怎么分更容易出现系统性偏差——同一个缺陷画大一圈、画小一圈，训练出来的模型就是两个东西。规则如下：

| 规则 | 要求 | 原因 |
|---|---|---|
| **框型** | 水平外接矩形（HBB），不旋转、不倾斜 | 本项目用 YOLOv8 的水平框输出；要旋转框得换 YOLOv8-OBB 重训，标注格式也随之改变 |
| **贴合度** | 紧贴缺陷外缘，不留均匀余量、也不刻意留白边 | 留余量会把背景像素算进正样本，召回虚高、定位变差 |
| **一实例一框** | 同类缺陷彼此分离时各标各的，不合并成一个大框 | 合并会让模型学不到个体边界，NMS 也无从区分 |
| **重叠框** | 成片缺陷（silk_spot）沿用上游的多个互相重叠的框，不合并、不拆分 | 沿用上游标注才能与公开结果比较；合并相当于改动 GT |
| **最小尺寸** | 不设最小尺寸阈值；人眼能稳定识别为异物残留就标 | 设阈值等于提前丢弃小目标，而小目标正是最难的部分（inclusion 30–60 px） |
| **越界** | 框必须完整落在图像内；归一化后任一边不得 < 0 或 > 1 | 越界框会让 letterbox 后的坐标还原出错，`scripts/check_labels.py` 会直接报出来 |
| **坐标格式** | YOLO txt：`cls cx cy w h`，五个字段全部归一化到 0–1 | Ultralytics 的约定，`cls` 即上表的 `#` 列 |
| **不许改 GT** | 不为「让模型更好训」而改动任何标注框 | 改了就没法跟公开结果对照，也掩盖了真实问题 |

> 标注文件与图片一一对应，同名的 `.jpg` 与 `.txt` 成对出现；良品图允许存在**空 txt**（0 字节），Ultralytics 会当背景图处理。

## 3 正例与反例（Positive / negative examples）

> 图片位置：`label_samples/`（该目录尚未提供示例图，本文以表格规则为准——此处如实标注，不假装有图）

### 3.1 crease（折痕）· 与 water_spot 的主战场

| | 判定 |
|---|---|
| **正例** | 明确的线状折线，长度 ≥ 5 倍宽度，走向与轧制方向平行或近邻平行 |
| **正例** | 折线两侧有轻微的高度差（表现为一侧略亮一侧略暗） |
| **反例** | 片状、边界模糊的亮/暗区域 → 判 `water_spot` |
| **反例** | 贯穿整幅板宽（长 = 2048 px）的窄带 → 判 `welding_line` |
| **边界案例** | **折痕位于反光带内、局部亮度分布呈片状** → **这是 25% 互混的来源**。规则：**优先看几何形态不看亮度**——只要主体是线状延伸就判 crease，哪怕局部像水斑 |

### 3.2 water_spot（水斑）

| | 判定 |
|---|---|
| **正例** | 片状区域，长宽比 < 5:1，边缘灰度渐变（无锐利边界） |
| **正例** | 多片聚集、形态随意、无固定走向 |
| **反例** | 有明确长轴方向的条带 → 判 `crease` |
| **反例** | 圆形/方形、内部全黑透空 → 判 `punching_hole` |
| **边界案例** | **片状水渍与片状油斑的区分**：水斑通常更亮（水反射），油斑更暗（油吸光）。但光照不均时这条不成立。**规则：亮 → water_spot，暗 → oil_spot，灰度接近背景时按纹理判断（水斑有轻微波纹，油斑更均匀）** |

### 3.3 inclusion（夹杂）· 小目标，模型的主要短板

| | 判定 |
|---|---|
| **正例** | 30–60 px 的暗色不规则小块，边缘相对锐利，孤立的点状/块状 |
| **反例** | 大面积的暗色弥散区域 → 判 `oil_spot` |
| **反例** | 规则的几何形状 → 判 `punching_hole` |
| **边界案例** | **< 30 px 的暗点算不算？** 本数据集的实际标注里包含更小的样本。规则：**只要人眼能稳定识别为异物残留就标**，不设最小尺寸阈值（这类样本模型本来就学不好，见 [`EVAL.md`](EVAL.md) 的逐类指标与失败案例） |

### 3.4 rolled_pit（轧制坑）· mAP 最低的类

| | 判定 |
|---|---|
| **正例** | 浅凹陷区域，明暗过渡柔和（无锐利边缘），常呈椭圆/不规则圆形 |
| **反例** | 有锐利边缘的凹痕（那是剪切/碰撞伤，不在本数据集十类内） |
| **边界案例** | **坑沿正好有线性高光时** 会被误判成 crease（本模型实测 14%）。规则：**看主体，看是否有凹陷的整体形态；单看一条高光线不足以判 crease** |

### 3.5 silk_spot（丝斑）· 重叠框问题最严重

| | 判定 |
|---|---|
| **正例** | 丝状/网状纹理异常区域，成片，边界由纹理密度变化决定 |
| **边界案例** | **同一片丝斑，标 1 个大框还是多个小框？** 本数据集的实际标注是**多个互相重叠的框**（见 [`EVAL.md`](EVAL.md) 失败案例一节的第 3 个案例）。这直接导致 NMS 把模型的多框输出压成 1 个。规则：**沿用上游标注，不为模型好训而改动 GT**——改了就没法和公开结果比 |

### 3.6 oil_spot / punching_hole / waist_folding / welding_line / crescent_gap

这五类的边界相对清晰，规则从简：

- **oil_spot**：暗色弥散片状；与 inclusion 的互混 14%（模型实测），规则同第 3.2 节的边界案例
- **punching_hole**：规则几何 + 全黑透空，几乎不会误判（0.942 mAP@0.5）
- **waist_folding**：腰部位置的折叠，形态不规则；与 welding_line 有 6% 互混
- **welding_line**：贯穿板宽的长条（长 = 整幅）。**这是区分 crease 的关键规则**
- **crescent_gap**：月牙形材料缺失，弧形是决定特征（0.907 mAP@0.5，最好的类）

## 4 歧义处理（Ambiguity handling）

上一节是逐类的具体规则，这一节是可以套到任何一张新图上的判断顺序：

1. **几何形态优先于亮度**。先看是线状、片状、弧形还是规则几何，亮度差异只在几何无法区分时才用。这一条直接对治 crease ↔ water_spot 的 25% 互混。
2. **与 `welding_line` 冲突时，先看是否贯穿整幅板宽**。贯穿（长 = 2048 px）判 welding_line，否则回头按几何形态判。
3. **与 `punching_hole` 冲突时，先看是否全黑透空 + 边界规整**。两条都满足才是孔，缺一条重判。
4. **类别归属拿不准（都像、或者都不像）**：按上面 1–3 的顺序先给一个类别，同时把样本放进「争议集」，交工艺工程师裁决。
5. **是不是缺陷拿不准（疑似反光、污渍、正常纹理）**：先不标，同样进争议集。漏标一个真缺陷比错标一个假缺陷更容易被发现。
6. **裁决结果必须写回本文档**。每裁决一个边界案例，规范就多一条规则；跑三轮之后，标注员之间的分歧会收敛到可接受范围。

## 5 标注工具与流程（Tooling & workflow）

### 5.1 工具（Tooling）

**本项目的数据直接来自公开数据集，未重新标注。** 若要在产线上自建数据集：

| 环节 | 推荐工具 | 理由 |
|---|---|---|
| 框标注 | LabelImg / CVAT | CVAT 支持多人协作 + 审核流，产线上更合适 |
| 格式转换 | 本项目 `scripts/` 下的脚本 | 输出 YOLO txt（`cls cx cy w h`，全部归一化到 0–1） |
| 质检 | `scripts/check_labels.py` | 本项目实测：查越界框 / ≤1px 微框 / 缺失标注 / 坏类别号 / 坏格式 |

### 5.2 流程（Workflow，产线自建数据集时必须遵守）

```text
1. 采样      从产线取图，覆盖不同班次 / 不同批次 / 不同灯管状态
2. 预筛      用当前模型跑一遍，把「模型有响应」的图优先送去标注（主动学习）
3. 双人标注  同一批图，两个标注员独立标，互不可见
4. 自动质检  scripts/check_labels.py 跑一遍，机械性错误先挡掉
5. 仲裁      两人不一致的样本，交工艺工程师裁决，裁决结果作为新规则补进本文档
6. 入库      通过质检 + 仲裁的样本进训练集；仲裁中的边界案例单独存一份「争议集」
7. 复盘      每轮训练后看混淆矩阵，把互混最高的两类拉出来重看本文档
```

**第 5 步是整条流程的价值所在**：每裁决一个边界案例，本文档就多一条规则。跑三轮之后，标注员之间的分歧会收敛到可接受范围。

## 6 质检规则（QC rules）

### 6.1 自动化检查（Automated checks，本项目已实现）

`scripts/check_labels.py` 检查六项：

| 检查项 | 判定 | 本数据集实测 |
|---|---|---|
| 越界框 | 归一化后任一边 < 0 或 > 1 | **0** |
| 微小框 | 宽或高 ≤ 1 px | **0** |
| 无标注图 | 有图片但无 txt | **0** |
| 空标注文件 | txt 存在但 0 字节 | **8**（train 7 + test 1，ultralytics 当背景图处理，可接受） |
| 坏类别号 | 不在 0–9 范围 | **0** |
| 坏格式行 | 字段数 ≠ 5，或坐标非数字 | **0** |

**结论：本数据集机械性质检全过。**

### 6.2 与官方 metadata 的交叉验证（Cross-check against upstream metadata）

GC10-DET 每个 split 目录带 `metadata.jsonl`，记录绝对像素坐标的 `objects.bbox` 和 `objects.categories`。逐张逐框对比本项目的 YOLO txt：

```text
checked 2300  ok 2300  bad 0                     # 类别编号 100% 一致
boxes 3563   max abs diff 5.000000000143778e-07  # 坐标误差在 float32 舍入极限
```

**这条验证比任何人工抽检都有说服力**：证明标注是官方原始标注，转换过程零误差。

### 6.3 人为检查（Manual spot checks，产线必做，本项目只做了抽样）

| 检查 | 频率 | 方法 |
|---|---|---|
| 框是否贴合缺陷 | 每批抽 5% | 叠图目视（参考 `runs/detect/train/train_batch0.jpg` 的样子） |
| 类别是否标对 | 每批抽 5% | 对照本文第 3 节的正反例 |
| 是否漏标 | 每批抽 2% | 全图扫一遍，确认没有遗漏的缺陷 |
| 重复图 | 每批一次 | pHash 汉明距离 ≤ 5（本项目实测抓到 2 对，距离均为 4，保留不删） |

## 7 禁标情形（Do-not-label cases）

以下情形**不要画框**。它们不是「标注员看不出来」，而是本来就不该进训练集：

| 情形 | 处理 | 原因 |
|---|---|---|
| **正常轧制纹理 / 压下量纹理**（无密度突变、无边界） | 不标 | 与 silk_spot 的混淆度最高，标进去等于教模型认错 |
| **镜面反光带、高光条**（无伴随缺陷形态） | 不标，并反馈给光学/工艺 | 反光会被当成 water_spot / silk_spot，这是产线上最主要的假阳性来源 |
| **镜头污渍、水汽、保护膜褶皱** | 不标，先修成像链路 | 属于采集侧问题，标进数据集等于把设备故障写进标签 |
| **十类之外的缺陷**（划伤、剪切碰撞伤、明显异物压入等） | 不标，单独记录 | 类别体系是十类闭集；混入新类会让类别语义打架，需要先扩类别再标 |
| **图像边缘被截断、且形态不足以判断类别** | 不标 | 半个形状既学不到特征，也会污染该类的外观分布 |

一条边界说明：能判断类别的截断缺陷，按**可见范围**画框（框仍然要落在图像内），并在备注里注明「截断」。这和上面「无法判断类别的截断形状」不是一回事。

## 9 给接手的工程师的话（Handoff notes）

如果你要在这个项目基础上继续做：

1. **不要为了提高 mAP 去改 GT 框。** 改了就没法和公开结果比，而且掩盖了真实问题。silk_spot 的重叠框很难训，但删掉重叠框等于骗自己。
2. **crease 和 water_spot 的互混，改模型没用。** 要么改标注口径（把两类合并成一类「表面色差」），要么在产线上加中间工序信息做特征。前者需要客户同意，后者需要产线改造。
3. **类别不均衡是真问题，但别急着开 `cls_pw`。** 本数据集正负样本 1:1，开加权反而有害。产线数据集才需要。
4. **每标注一轮，回来更新这份文档。** 一份三个月没更新的标注规范，说明没人真正在管数据质量。
